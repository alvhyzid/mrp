# Daftar Database — Format Sederhana

Dokumen pendamping dari `rancangan-skema-database-mrp.md`. Tiap tabel ditulis sebagai satu "database" berdiri sendiri dengan daftar field-nya — nama field pakai Bahasa Indonesia, nama teknis (untuk Supabase) di dalam kurung.

**Konvensi penamaan ID:** setiap primary key memakai pola `nama_tabel_tunggal_id` (mis. tabel `employees` → primary key `employee_id`). Ini membuat nama field konsisten di mana pun dipakai — nama yang sama persis dipakai saat tabel lain mereferensikannya sebagai foreign key.

---

## Kelompok 1: Akses & Tenant

**Database Perusahaan** (`companies`)
- ID Perusahaan (company_id)
- Nama Perusahaan (name)
- Jenis Industri (industry_type)
- ID Paket Langganan (subscription_plan_id)
- Status (status)
- Tanggal Dibuat (created_at)

**Database Paket Langganan** (`subscription_plans`)
- ID Paket (subscription_plan_id)
- Nama Paket (name)
- Harga (price)
- Siklus Tagihan (billing_cycle)
- Maksimal User (max_users)
- Maksimal Item (max_items)

**Database Pengguna/Login** (`users`)
- ID User (user_id)
- ID Perusahaan (company_id)
- Nama (name)
- Email (email)
- Password (password_hash)
- Peran/Role (role)
- Status (status)

## Kelompok 2: Master Data Produksi

**Database Shift Kerja** (`shifts`)
- ID Shift (shift_id)
- ID Perusahaan (company_id)
- Nama Shift (name)
- Jam Mulai (start_time)
- Jam Selesai (end_time)
- Status Aktif (is_active)

**Database Gangguan Produksi** (`production_disruptions`)
- ID Gangguan (production_disruption_id)
- ID Perusahaan (company_id)
- Jenis Gangguan (disruption_type)
- ID Mesin Terkait (work_center_id)
- ID Work Order Terkait (work_order_id)
- ID Tahap Terkait (routing_step_id)
- ID Shift (shift_id)
- Waktu Mulai (started_at)
- Waktu Selesai (resolved_at)
- Keterangan (description)

**Database Pekerja** (`employees`)
- ID Pekerja (employee_id)
- ID Perusahaan (company_id)
- Nama (name)
- Posisi (position)
- Jenis Upah (wage_type)
- Tarif Upah (wage_rate)
- ID User Terkait (linked_user_id)
- Status Aktif (is_active)

**Database Pengaturan Perusahaan** (`company_settings`)
- ID Pengaturan (company_setting_id)
- ID Perusahaan (company_id)
- Kunci Pengaturan (setting_key)
- Nilai Pengaturan (setting_value)

**Database Bahan/Produk** (`items`)
- ID Item (item_id)
- ID Perusahaan (company_id)
- Kode Item (item_code)
- Nama Item (name)
- Tipe: bahan mentah/setengah jadi/produk jadi/kemasan (type)
- Satuan (uom)
- Umur Simpan dalam Hari (shelf_life_days)
- Stok Minimum (min_stock_level)
- Titik Pesan Ulang (reorder_point)
- Jumlah Pesan Ulang Standar (reorder_qty)
- Status Aktif (is_active)
- Biaya Standar (standard_cost)

**Database Resep/Komposisi** (`boms`)
- ID BOM (bom_id)
- ID Perusahaan (company_id)
- ID Item Induk (parent_item_id → merujuk ke item_id)
- Versi (version)
- Jumlah Hasil Standar (standard_yield_qty)
- Satuan Hasil (standard_yield_uom)
- Status (status)

**Database Detail Komponen Resep** (`bom_lines`)
- ID Baris (bom_line_id)
- ID BOM (bom_id)
- ID Item Komponen (component_item_id → merujuk ke item_id)
- Jumlah per Unit Output (qty_per_unit_output)
- Satuan (uom)

**Database Mesin/Stasiun Kerja** (`work_centers`)
- ID Mesin (work_center_id)
- ID Perusahaan (company_id)
- Nama Mesin (name)
- Kode Mesin (code)
- Status Aktif (is_active)

**Database Header Alur Produksi** (`routings`)
- ID Routing (routing_id)
- ID Perusahaan (company_id)
- ID Item (item_id)
- Versi (version)

**Database Tahapan Produksi** (`routing_steps`)
- ID Tahap (routing_step_id)
- ID Routing (routing_id)
- Nomor Urut (sequence_no)
- Nama Tahap (step_name)
- Durasi Kerja Aktif dalam Menit (active_duration_minutes)
- Durasi Tunggu dalam Menit (wait_duration_minutes)
- ID Mesin (work_center_id)

**Database Referensi Formula** (`formula_templates`)
- ID Formula (formula_template_id)
- ID Perusahaan (company_id)
- Nama (name)
- Catatan (notes)
- Komposisi Referensi (reference_composition)

**Database Pergerakan Stok** (`stock_movements`)
- ID Pergerakan (stock_movement_id)
- ID Perusahaan (company_id)
- ID Lot (lot_id)
- Jenis Pergerakan (movement_type)
- Jumlah (qty)
- Dokumen Referensi (reference_doc)
- Tanggal (created_at)
- Dibuat Oleh (created_by)

## Kelompok 5: Produksi

**Database Perintah Produksi** (`work_orders`)
- ID Work Order (work_order_id)
- ID Perusahaan (company_id)
- ID Item (item_id)
- ID BOM (bom_id)
- ID Routing (routing_id)
- ID SO Line Asal (sales_order_line_id)
- Jumlah Rencana (planned_qty)
- Status (status)
- Jadwal Mulai (scheduled_start)
- Jadwal Selesai (scheduled_end)
- Waktu Aktual Mulai (actual_start_at)
- Waktu Aktual Selesai (actual_completed_at)
- ID Subkontraktor (subcontractor_id)

**Database Hasil Produksi** (`work_order_outputs`)
- ID Hasil (work_order_output_id)
- ID Work Order (work_order_id)
- ID Item Hasil (item_id)
- ID Shift (shift_id)
- Jenis Output: produk utama/sisa bisa dipakai lagi/sisa dibuang (output_type)
- Jumlah (qty)
- ID Lot Baru (lot_id)

**Database Bahan Terpakai** (`work_order_consumption`)
- ID Pemakaian (work_order_consumption_id)
- ID Work Order (work_order_id)
- ID Lot Komponen (component_lot_id → merujuk ke lot_id)
- Jumlah Terpakai (qty_consumed)
- ID Shift (shift_id)
- Waktu Dicatat (recorded_at)

**Database Penugasan Pekerja** (`work_order_assignments`)
- ID Penugasan (work_order_assignment_id)
- ID Work Order (work_order_id)
- ID Pekerja (employee_id)
- ID Tahap Terkait (routing_step_id)
- ID Shift (shift_id)
- Status: rencana/konfirmasi/absen/diganti/selesai/tambahan mendadak (status)
- ID Penugasan yang Digantikan (replacement_for_assignment_id → merujuk ke work_order_assignment_id)
- Jam Rencana (scheduled_hours)
- Jam Aktual (actual_hours)
- Jumlah Dihasilkan — khusus upah per pieces (qty_produced)

**Database Progres Tahap Produksi** (`work_order_step_progress`)
- ID Progres (work_order_step_progress_id)
- ID Work Order (work_order_id)
- ID Tahap (routing_step_id)
- ID Shift (shift_id)
- Status: menunggu/berjalan/selesai (status)
- Jumlah Tercatat (qty_recorded)
- Satuan (uom)
- Waktu Mulai (started_at)
- Waktu Selesai (completed_at)
- Catatan (notes)

**Database Notifikasi Sistem** (`system_alerts`)
- ID Alert (system_alert_id)
- ID Perusahaan (company_id)
- Jenis Alert (alert_type)
- ID Work Order Terkait (related_work_order_id)
- ID PO Terkait (related_po_id)
- ID Item Terkait (related_item_id)
- Pesan (message)
- Tingkat Keparahan (severity)
- Status (status)
- Tanggal Dibuat (created_at)
- Dikonfirmasi Oleh (acknowledged_by)
- Waktu Dikonfirmasi (acknowledged_at)
