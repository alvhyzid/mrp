# FABRIX Carbon Component Checklist

Use this checklist before introducing or changing a UI component.

## Foundations

- [ ] Carbon typography
- [ ] Carbon color/tokens
- [ ] Carbon spacing
- [ ] Carbon grid/layout
- [ ] Carbon iconography
- [ ] Theme compatibility
- [ ] Responsive behavior

## Actions

- [ ] Button
- [ ] Link
- [ ] Menu
- [ ] Overflow/menu button
- [ ] Content switcher

## Forms

- [ ] Form
- [ ] Text input
- [ ] Number input
- [ ] Select
- [ ] Dropdown
- [ ] ComboBox/Multiselect where applicable
- [ ] Checkbox
- [ ] Radio
- [ ] Toggle
- [ ] Date picker
- [ ] File uploader
- [ ] Validation/error presentation

## Data

- [ ] Data table
- [ ] Search
- [ ] Filtering
- [ ] Pagination
- [ ] Tags/status
- [ ] Empty state
- [ ] Loading state
- [ ] Error state

## Feedback

- [ ] Notification
- [ ] Toast/appropriate Carbon feedback pattern
- [ ] Inline loading
- [ ] Progress
- [ ] Tooltip
- [ ] Toggletip
- [ ] Popover

## Navigation/layout

- [ ] UI shell
- [ ] Breadcrumb
- [ ] Tabs
- [ ] Accordion
- [ ] Side panel/page pattern
- [ ] Modal/dialog pattern

## Before custom UI

- [ ] Carbon equivalent searched
- [ ] Carbon Usage checked
- [ ] Carbon Style checked
- [ ] Carbon Code checked
- [ ] Carbon Accessibility checked
- [ ] Installed version verified
- [ ] Existing FABRIX wrapper checked
- [ ] Custom deviation documented if necessary
