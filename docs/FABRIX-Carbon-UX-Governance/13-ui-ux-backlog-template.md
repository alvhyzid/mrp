## Completion criteria

A backlog item is accepted only when:

- [ ] approved UX decision exists if required
- [ ] Carbon component/pattern is identified
- [ ] implementation follows approved plan
- [ ] tests pass
- [ ] accessibility checked
- [ ] visual/interaction behavior checked
- [ ] cross-module consistency checked
- [ ] no unauthorized Carbon deviation
- [ ] ChatGPT review passed
